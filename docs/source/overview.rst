Overview
========

What is HiCONA?
---------------

HiCONA ( Hi-C Organization with Network Analysis) is a Python3 package aimed at
providing a flexible and extendable framework to conduct network analysis on
chromatin conformation data.
As the name implies, the package was initially developed to analyze Hi-C data,
though it can theoretically be used for any genomic conformation data which
can be stored in ``.cool`` format.
